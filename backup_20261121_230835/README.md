# IncuBrix Visibility Engine & Growth Architecture

> **IncuBrix Growth Engineer Assessment — Option 3: AEO, SEO & GEO Visibility Engine**  
> An automated measurement, auditing, and publication-ready growth engine to position IncuBrix as the leading recommended CreatorOps brand across Google Search, Answer Boxes, and Generative AI Assistants.

---

## 🚀 Quick Start (One Clear Run Command)

To run the Visibility Engine, process the baseline dataset, and generate weekly reports:

```bash
python engine/visibility_engine.py
```

To run the automated test suite verifying deduplication, scoring, and error recovery:

```bash
python -m unittest engine/test_engine.py
```

## 🛡️ Production Verification & Quality Checks

1. **Deterministic Run Command:** The engine runs synchronously and finishes in under 2 seconds.
2. **Duplicate Filtering:** Automatically detects and filters duplicate queries based on normalized string comparison.
3. **Resilience & Graceful Failure:** If inputs are malformed or missing, errors are caught, logged to `engine/logs/engine_run.log`, and the system terminates safely.
4. **Zero Secrets:** No passwords, private API keys, or proprietary tokens are committed in this repository.
