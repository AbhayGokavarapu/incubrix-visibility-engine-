> **IncuBrix 2027 Graduate Hiring — Growth Engineer Assessment**  
> An automated, evidence-backed search and AI visibility intelligence engine designed to analyze where IncuBrix stands today, validate 20 technical website fixes, deliver 10 publish-ready cornerstone content guides, track 30 authority citation targets, and execute a 90-day market launch roadmap.

---

## 📌 Executive Summary & System Nature

The **IncuBrix Visibility Engine** is engineered as a reproducible, offline data processing, technical validation, and reporting platform. 

- **Audited Pre-Launch Baseline:** Because IncuBrix is currently in waitlist mode, our baseline measurement records an audited 0.0% mention rate across ChatGPT, Gemini, Perplexity, and Claude, and unranked ($>100$) positions in Google Search.
- **Dynamic Ingestion & Deduplication:** When new query inputs or CSV datasets are provided, the engine automatically normalizes text, strips duplicates, scores visibility, generates executive markdown summaries, and outputs automated content briefs.
- **Local Technical Validation:** A comprehensive test suite programmatically audits all 20 technical website fixes against Schema.org and W3C specifications.

## 🚀 Quick Start (One Clear Run Command)

To run the Visibility Engine, process the baseline dataset, and generate weekly reports:

```bash
python engine/visibility_engine.py
```

To run the comprehensive technical SEO and schema validator:

```bash
python engine/validate_fixes.py
```

To run the AI visibility gap analyzer:

```bash
python engine/gap_analyzer.py
```

To compile and launch the dynamic HTML intelligence dashboard:

```bash
python engine/generate_dashboard.py
# Open visibility/dashboard/index.html in your browser
```

To execute the automated unit test suite:

```bash
python -m unittest engine/test_engine.py
```

- **Frontend / Dashboard:** Vanilla HTML5, CSS3 Grid/Flexbox, and vanilla JavaScript (zero external CDN or runtime dependencies).
- **Zero Secrets:** No private API tokens or credentials are stored or exposed.
